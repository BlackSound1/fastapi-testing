# Simple FastAPI Project

This is a simple full-stack FastAPI-based REST API and webapp project.

# Stack

- Language: Python
- Framework: FastAPI
- Package manager, version manager: UV
- Database: PostgreSQL with SQLAlchemy ORM and Alembic migrations
- Storage: AWS S3 via Boto3
- Image processing: Pillow
- Auth: JWT
- Email testing: Mailtrap
- Docs: Swagger
- Frontend: CSS3, HTML5, JavaScript, Jinja2 templates
- Command runner: Just
